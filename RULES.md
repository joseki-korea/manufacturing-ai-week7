# Repository rules

Follow the [vault rules](https://github.com/joseki-korea/solucionemos-vault/tree/main/rules) and preserve existing notebook results. Use a branch and draft PR for changes; do not commit credentials or private data. Store large binary assets in Drive and document provenance. Move files only after reference and execution checks.

## 핸드오프 절차
1. 일을 넘길 때는 `docs/agents/handoffs/active/`에 TEMPLATE.md 복사본을 만든다.
2. 파일명, append-only, ACK, archive 규칙은 [핸드오프 규칙](docs/agents/handoffs/README.md)을 따른다.
3. 끝난 핸드오프는 `docs/agents/handoffs/archive/`로 옮긴다.
