# 세션 핸드오프

## 사용법

핸드오프마다 별도 Markdown 파일을 추가하고 세션 ID, 기기, 날짜, 상태를 frontmatter에 기록합니다. 기존 기록은 보존합니다. 파일명은 날짜와 세션 ID를 사용합니다. 비밀값, 토큰, 개인정보를 넣지 않습니다.

컨텍스트 핸드오프 Markdown 파일은 `active/`에 두고, 세션을 재개하면 `archive/`로 이동합니다.
